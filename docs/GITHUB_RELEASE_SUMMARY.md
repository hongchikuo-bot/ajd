# AJD v0.5.0 — Release Summary & User Guide

## Quick Start

### With AI Agent (Recommended)
```bash
curl -fsSL https://raw.githubusercontent.com/hongchikuo-bot/ajd/release/v0.5.0/install.sh | bash
# Then read AGENTS.md in installation directory for your agent-specific setup
```

### Manual Setup
```bash
curl -fsSL https://raw.githubusercontent.com/hongchikuo-bot/ajd/release/v0.5.0/install.sh | bash
cd <installation-path> && bash manual_setup.sh
```

## Safety & Privacy

- ✅ **Never uploads data** — all operations are local-only
- ✅ **Reads only $AJD_HOME**, never modifies your projects
- ✅ **Uses `$AJD_HOME` env var**, no hardcoded paths like `/Users/macmima1234`
